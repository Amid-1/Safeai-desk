# 7.5G.3 — пользовательские сценарии Auth, Chat, Knowledge

## Границы ответственности

Backend остаётся источником решений о сессии, правах, лимитах и обработке документов.
Frontend показывает состояние и допустимые действия. Изменений Java, SQL, Redis,
модели ролей, API-контрактов и зависимостей в данном этапе нет.

## Auth

- Вход с рабочей учётной записью. Пароль скрыт по умолчанию; показать/скрыть можно с клавиатуры.
- При отправке формы пароль вновь скрывается. Не сохраняется в браузерном хранилище.
- Действующие обработчики 401, 403, 429, Retry-After, 503 и восстановления сессии (7.5G.1) сохранены.
- Неподтверждённый выход не выдаётся за успешный; повторная попытка доступна.

## Chat

- Обычный AI доступен независимо от загрузки каталога баз знаний.
- Режимы с корпоративными знаниями требуют выбранную активную базу, не находящуюся в удалении.
- GET /api/knowledge-bases загружает страницы по 100 записей; повтор/следующая страница — явно.
- Ошибка каталога отличается от пустого списка. Черновик и режим остаются неизменными.
- Проверка возможности отправки выполняется также в обработчике отправки с клавиатуры.
- POST отправки не инициируется при неподтверждённой базе. Сервер повторно проверяет права.
- Механизмы идемпотентности и сверки неопределённого результата 7.5G.1 сохранены.
- Пользователь видит ответ, источники, понятные состояния. Служебные ID — в подробностях.
- Демонстрационный ответ явно обозначен; не выдаётся за внешний AI.
- Черновик сохраняется при изменении режима и адаптивном reflow, не обещается сохранение после reload.

## Knowledge

- Собственные контроллеры каталога, доступа, документов, версий, загрузки и удаления находятся
  в features/knowledge/controller. Chat использует общий entities/knowledge API.
- GET /api/knowledge-bases, /search: загрузка, пустая выдача, ошибка и повтор различаются.
- GET /api/knowledge-bases/{id}, /access, /documents/health: проверка согласованности ID;
  при отказе не показываются старые сведения, документы и действия управления.
- GET /api/knowledge-bases/{id}/documents: пагинация и отдельное состояние ошибки.
- Готовность документов к поиску не является обещанием корректности будущего AI-ответа.
- Технические подробности обработки показываются редакторам по запросу; не заменяют проверку прав.
- Загрузка новой версии сохраняет предыдущую согласно backend-контракту.
- Пока идёт загрузка, окно нельзя случайно закрыть через обычные способы закрытия Modal.

## Архитектура и приёмка

- Новое правило запрещает прямые зависимости chat → knowledge и knowledge → chat.
- Auth остаётся источником клиентского контекста сессии; маршруты и серверный ACL неизменны.
- Полный CI: architecture:check, lint без предупреждений, test:coverage, build.
- Browser: platform-responsive.spec.cjs, в том числе отказ каталога знаний и восстановление выбора.
- Синтетические E2E не доказывают серверный ACL. Реальный staging и аварийные сценарии — 7.5G.7 / 7.5C.
- Не считать этап принятым до полного CI и целевых браузерных проверок в репозитории.
