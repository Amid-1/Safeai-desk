# Матрица полной production-приёмки SafeAI Desk

Версия: 20.11.2026. Все строки начально NOT RUN, если отдельно не предъявлен
протокол запуска. Матрица — критерии, а не заявление о прохождении тестов.
P0/P1 обязательны. P2 тоже обязательны, если отмечены в release policy.

Обозначения: J — JUnit/Testcontainers, A — прямой API, B — браузер,
D — SQL/Redis/S3, S — staging, I — инфраструктура, R — ручное ревью.
Точные сценарии HTTP строить по фактическому контракту, не по предположениям.

## Формат протокола

Для каждого ID: SHA приложения, digest образа, дата UTC, окружение,
идентификатор запуска, шаги, результат PASS/FAIL/BLOCKED/NOT RUN/N/A,
артефакт и SHA-256 отчёта, ответственный. Для J/A — имя класса и метода.
Для B — spec и название сценария. Для S/I — согласованный стенд и его конфигурация.
Для FAIL — связанное замечание и результат повторной проверки.

Существующие unit/integration/Playwright тесты связываются с ID после проверки
assertions и области действия. Для новых AI-07..10 и AUD-11..14 нужны отдельные
реализация и тесты; наличие этой матрицы не считается прохождением.
