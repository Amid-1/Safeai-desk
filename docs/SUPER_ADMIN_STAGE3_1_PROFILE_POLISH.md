# SafeAI Desk — Super Admin Stage 3.1: карточки и навигация

**Дата:** 18.11.2026. **Зависимость:** установленные этапы 2 и 3. **Статус:** кандидат, требует локальной и браузерной проверки.

## Изменения

- В каталоге организаций название теперь открывает ту же серверную карточку, что кнопка «Подробнее».
- Вторую вертикальную кнопку «Переименовать» заменяет меню дополнительных действий `⋯`. Переименование и включение/отключение используют те же обработчики и подтверждения. Для защищённой системной организации меню недоступно.
- Карточки пользователя и организации получили единый визуальный стиль: читаемая шапка, аватар/буква, явные статусы и блоки сведений. В карточке организации сохранены четыре tenant-связанных URL-перехода.
- Обе карточки можно перемещать ЛКМ за заголовок и разворачивать отдельной кнопкой либо двойным щелчком по заголовку. Изменение размера за края намеренно выключено. Размеры ограничены видимой областью, тело карточки прокручивается отдельно.
- UUID и версии находятся в скрытых по умолчанию технических сведениях. SUPER_ADMIN имеет доступ к техническим сведениям пользователя, ADMIN не получает новые права.
- Таблица пользователей получает более компактные колонки при ширине viewport от 1280 px; при узкой ширине горизонтальный скролл сохранён, чтобы не скрывать действия.

## Неизменённые контракты

Backend, PostgreSQL, Flyway V1–V92, сессии, CSRF, аудит, model policy, RBAC, optimistic version, tenant isolation, серверные фильтры и пагинация не изменены. Все опасные операции по-прежнему требуют существующих подтверждений на сервере.

## Приёмка (Mac / CI)

1. Открыть название и «Подробнее» одной организации, сравнить карточку и переходы.
2. Для клиентской организации открыть `⋯`, проверить переименование и диалог отключения с подтверждением. Для SafeAI Platform эти действия недоступны.
3. Проверить переходы из карточки к пользователям, правилам моделей, расходам и аудиту с сохранённым `organizationId`/`targetOrganizationId`.
4. Проверить карточку пользователя: отображение имени, почты, организации, последнего входа; технические сведения видны только при нужных правах.
5. Переместить обе карточки мышью, развернуть, восстановить, изменить размеры окна браузера. Проверить Escape, Tab, focus trap, 390×844, 1280×720 и 1440×900.
6. Проверить TypeScript, ESLint, целевые Vitest, production build и E2E на Mac; затем полный CI. Не считать этап прошедшим только по ZIP.
