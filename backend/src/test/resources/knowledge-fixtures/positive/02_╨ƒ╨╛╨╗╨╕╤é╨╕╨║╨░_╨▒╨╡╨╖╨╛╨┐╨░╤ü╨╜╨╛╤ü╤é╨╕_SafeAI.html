SafeAI Desk - Политика безопасности базы знаний

Этот файл предназначен для ручной и автоматической проверки HTML-загрузок. Он является обычным корректным HTML-документом в UTF-8.

1. Изоляция данных

Каждая база знаний принадлежит одной организации. Пользователь не должен получать документы другой организации даже при прямом указании идентификатора.

2. Уровни доступа

  • VIEWER - просмотр.
  • EDITOR - просмотр и загрузка версий.
  • OWNER - полный ресурсный доступ.

3. Файлы

Сервер определяет фактический формат файла по содержимому. Клиентский Content-Type не является доверенным источником.

4. Аудит

Значимые действия записываются в аудит: создание базы, изменение участников, загрузка версии и скачивание документа.

Контрольный маркер: INCIDENT-SLA-20-MIN.
