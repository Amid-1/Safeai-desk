Политика безопасности SafeAI Desk

Контрольная фраза: CERBERUS-91

1. Identity

Access JWT содержит минимальный набор identity/security claims. Email хранится в профиле пользователя и API-ответах, когда он нужен бизнес-функции, но не обязан находиться в access token.

2. Storage

PostgreSQL хранит metadata, MinIO/S3 — байты knowledge-документов, Redis — временное coordination state.

3. Запрещённые данные в логах

  • password
  • raw JWT
  • refresh token
  • cookies
  • API keys
  • полные чувствительные документы
